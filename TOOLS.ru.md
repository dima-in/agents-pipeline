# TOOLS.ru.md - Локальные заметки

Русскоязычная версия [TOOLS.md](./TOOLS.md). Оригинал остаётся основным источником, если появятся расхождения.

Skills описывают, _как_ работают инструменты. Этот файл нужен для _твоих_ локальных особенностей — всего, что уникально для конкретной установки.

## Что сюда записывать

Например:
- названия и расположение камер
- SSH-хосты и алиасы
- предпочтительные голоса для TTS
- названия колонок и комнат
- прозвища устройств
- любые environment-specific детали

## Пример

```markdown
### Cameras

- living-room -> Main area, 180-degree wide angle
- front-door -> Entrance, motion-triggered

### SSH

- home-server -> 192.168.1.100, user: admin

### TTS

- Preferred voice: "Nova" (warm, slightly British)
- Default speaker: Kitchen HomePod
```

## Почему отдельно

Skills могут быть общими. Твоё окружение — нет. Если держать это отдельно, можно обновлять skills без потери локальных заметок и делиться skills без утечки инфраструктурных деталей.
